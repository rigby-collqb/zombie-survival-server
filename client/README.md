# Zombie Survival Online — Cliente Fase 22

Cliente HTML/CSS/JS para InfinityFree / `zombiesurvival.gt.tc`.

## Fase 22
- 5 mapas distintos: Cidade Abandonada, Distrito Hospitalar, Floresta Sombria, Zona Militar Ômega e Complexo Industrial.
- Colisão revisada: paredes longas agora entram corretamente na busca de colisão e árvores têm troncos físicos mais coerentes com o visual.
- Música original em arquivos MP3 para menu, exploração, combate, boss e morte, com transições dinâmicas.
- Capa cinematográfica na home.
- Ranking global com fallback HTTP e retry automático após cold-start do Render.
- Código de amigo/social atualizado automaticamente depois que o servidor acorda.

Ao publicar, preserve o seu `api/config.php` real. O pacote distribui apenas `config.example.php`.
